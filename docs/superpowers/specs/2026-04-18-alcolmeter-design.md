# Alcolmeter - 양조 계산기 설계 문서

## 개요

서버 연동 없이 동작하는 양조 배합 계산기. 쌀 총량과 쌀 형태를 입력하면 단양주/이양주/삼양주 각각에 대해 단계별 이상적인 물과 누룩의 양을 자동으로 계산한다.

**서비스명**: 알콜미터 (Alcolmeter)
**버전**: 0.1.0 (MVP)
**사용자**: 황지훈(양조 담당) + 이윤신(마케팅/IT 담당)
**배포**: Vercel (정적 사이트)
**저장소**: TransparentDeveloper (GitHub private repo)

## MVP 범위

- 막걸리 계산기만 구현
- 누룩은 송학곡자 고정 (추후 누룩 종류 선택 확장)
- 사이다/와인은 추후 확장 (메인 페이지에 "준비 중" 표시)

## 기술 스택

- **SvelteKit** + adapter-static (SPA 모드, 정적 빌드)
- **TypeScript**
- **Vercel** 배포

## 입력값

| 항목 | 타입 | 설명 |
|------|------|------|
| 쌀 총량 | 숫자 (ℓ 기본, g 전환 가능) | 사용할 쌀의 총 부피. 전통주에서는 ℓ(되) 단위가 표준 |
| 밑술 쌀 형태 | 선택 (떡/범벅/죽) | 밑술에 투입할 쌀의 가공 형태. 추후 타입 추가 가능 |

## 출력값

단양주 / 이양주 / 삼양주 탭별로 각 단계의 재료 양을 테이블로 표시한다.

### 단양주

전량 한 번에 투입. 별도 분배 없음.

### 이양주 (밑술 + 덧술)

| 단계 | 쌀 | 물 | 누룩 |
|------|-----|-----|------|
| 밑술 | 쌀 총량의 1/3 | 쌀 형태 비율에 따라 자동 계산 | 전량 투입 |
| 덧술 | 쌀 총량의 2/3 | - | - |

### 삼양주 (밑술 + 덧술 + 덧술2)

| 단계 | 쌀 | 물 | 누룩 |
|------|-----|-----|------|
| 밑술 | 쌀 총량의 1/6 | 쌀 형태 비율에 따라 자동 계산 | 전량 투입 |
| 덧술 | 쌀 총량의 1/6 | 밑술과 동일한 쌀 형태 비율로 자동 계산 | - |
| 덧술2 | 쌀 총량의 4/6 | - | - |

> 참고: 위 분배 비율은 전통주 일반 공식 기반이며, 실제 프로덕션에서 지훈의 검증 필요.

## 핵심 계산 규칙

### 밑술 쌀 형태별 쌀:물 비율

| 쌀 형태 | 쌀:물 비율 | 설명 |
|---------|-----------|------|
| 떡 (설기) | 1:1 | 쌀 1ℓ당 물 1ℓ |
| 범벅 | 1:3 | 쌀 1ℓ당 물 3ℓ |
| 죽 | 1:5 | 쌀 1ℓ당 물 5ℓ |

이 비율은 밑술에 적용된다. 삼양주의 첫 번째 덧술에서도 밑술과 동일한 쌀 형태를 사용하므로 같은 비율이 적용된다.

### 누룩 규칙

- **누룩은 밑술에만 전량 투입한다.**
- 이유: 덧술에 누룩을 추가하면 과발효가 일어나 맛과 향이 변질될 수 있다.
- 이 안내 문구를 UI에 표시한다.
- MVP에서는 **송학곡자 (당화력 300 SP)** 고정.
- 누룩 적정량: 송학곡자 기준으로 밑술 쌀 무게의 약 10~15%. 예: 쌀 1kg → 누룩 100~150g. (지훈 검증 후 정확한 비율 확정 예정)

### 쌀:물 비율에 따른 맛 변화 (참고 정보로 UI에 표시)

| 쌀 | 물 | 맛 | 설명 |
|-----|-----|-----|------|
| 1 | 1 | 기본 | 쌀과 물의 양을 동일하여 평균적인 맛 |
| 1 | 0.8 | 단맛 | 쌀 양(전분)이 많아 당이 많이 생성되어 단맛 강화 |
| 1 | 1.2 | 쓴맛/신맛 | 물의 양 대비 전분의 양이 적어 당도 낮고 알코올도수 낮아짐 |

### 계량단위 참고

| 구분 | 홉, 합 (合) | 되, 승 (升) | 말, 두 (斗) |
|------|------------|------------|------------|
| 리터 | 0.1ℓ | 1ℓ | 10ℓ |

## UI 흐름

### 메인 페이지 (`/`)
- 알콜미터 로고
- 술 종류 선택: 막걸리 (활성) / 사이다 (준비 중) / 와인 (준비 중)

### 막걸리 계산기 (`/makgeolli`)
- **입력 폼 (상단)**:
  - 쌀 총량 (숫자 입력, 단위 선택 가능)
  - 밑술 쌀 형태 (떡/범벅/죽 선택)
- **결과 (하단)**:
  - 3개 탭: 단양주 / 이양주 / 삼양주
  - 각 탭에 단계별 재료 테이블 (쌀, 물, 누룩의 실제 양)
  - 안내 문구: 누룩이 밑술에만 들어가는 이유
  - 입력값 변경 시 실시간 재계산 (리액티브)

### 반응형 레이아웃
- 모바일: 입력 폼과 결과가 세로 스택
- PC: 좌우 배치
