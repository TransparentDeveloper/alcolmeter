# 변경 이력 — 알콜미터 extension

> 각 판(版)은 *이탤릭 인용문*으로 그날의 짧은 이야기를 연 뒤,
> 무엇이 바뀌었는지 또렷한 항목으로 잇습니다. — 양조장 밤일지

## [0.3.0] — 2026-06-27

> *web이 먼저 갈아입은 측정 노트의 차림새를, 확장 팝업도 뒤늦게 똑같이 물려받았습니다. 먹빛 바탕에 붉은 불꽃 한 점, 같은 얼굴의 아이콘까지 한 식구로 맞췄습니다.*

- **디자인시스템 적용**: 팝업 전체를 web과 같은 「측정 노트」 색·활자·여백·모서리로 새로 입혔습니다. 예상 도수·생산량 같은 핵심 수치는 붉은 불꽃으로 또렷이 새깁니다. (design-system 0.3.2)
- **자동 다크 모드**: 브라우저·OS가 어두운 테마면 팝업도 따라 어두워집니다. 따로 켤 것은 없습니다.
- **새 아이콘**: 툴바·스토어 아이콘과 팝업 로고를 web과 똑같은 먹빛 불꽃 얼굴로 교체했습니다.
