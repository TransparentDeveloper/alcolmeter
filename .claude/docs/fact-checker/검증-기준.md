# 검증 기준

블로그 글의 주장을 유형별로 어떤 출처로, 얼마나 엄격하게 검증할지 정한다. 쓸 수 있는 출처의 종류와 참고 자료 형식은 `.claude/docs/blog-content-reviewer/글쓰기.md` 의 "출처" 절을 따른다.

## 유형별 기준

| 태그 | 대상 | 통과 기준 |
| --- | --- | --- |
| 수치 | 도수, 온도, 시간, 비율, 통계 | 1차 출처의 값과 단위, 조건(무엇의, 어느 단계에서)이 모두 일치한다. 출처마다 값이 다르면 범위로 쓰고 출처를 모두 단다. |
| 원리 | 발효·증류·숙성 같은 공정의 작동 방식 | 양조 교재나 학술 자료와 내용이 같다. 쉽게 풀어 쓰면서 뜻이 바뀌었으면 틀림이다. |
| 역사 | 기원, 연도, 어원, 인물, 사건 | 서로 독립된 출처 2개 이상이 같은 내용을 말한다. 한 출처를 다른 곳이 옮겨 적은 것은 1개로 센다. |
| 제품 | 특정 술의 원료, 제조사, 숙성 기간, 도수 | 제조사 공식 자료나 라벨 정보와 일치한다. 근거에 확인한 날짜를 적는다. |
| 법령 | 주세법 등 법령과 행정 기준 | 국가법령정보센터의 현행 조문과 일치한다. 근거에 조문 번호와 시행일을 적는다. |

## 출처의 질

모든 유형에 공통으로 본다.

- 출처가 주장을 실제로 말해야 한다. 같은 주제를 다룬다는 것만으로는 근거가 되지 않는다.
- 2차 출처가 1차 출처를 인용하고 있으면 1차 출처를 찾아 확인한다.
- 같은 내용을 여러 블로그가 되풀이하는 것은 출처 여러 개로 치지 않는다.
