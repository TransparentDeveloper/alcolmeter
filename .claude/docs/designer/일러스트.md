# 일러스트

## 전제 (사용자 결정)

- 일러스트는 Recraft 로 만든다.
- 광고 일러스트(advertising illustration) 톤으로 모든 글이 같은 분위기를 유지한다.
- 이미지 안에 글자를 넣지 않는다.
- 특정 제품의 사진, 상표, 라벨을 쓰지 않는다.

## 톤

광고 일러스트처럼 대상이 선명하고, 형태가 단순하고, 밝고 깨끗하다. 한 장만 봐도 무엇을 하는 장면인지 알 수 있어야 한다.

- 형태: 대상을 단순한 도형으로 정리한 평면 위주 그림. 부드러운 그라데이션과 약한 입체감(한 방향 빛, 부드러운 그림자)까지 허용한다.
- 외곽선: 쓰지 않는다. 면과 색으로 형태를 구분한다.
- 질감: 쓰지 않는다. 노이즈, 그레인, 종이 질감을 넣지 않는다.
- 빛: 모든 그림에서 왼쪽 위에서 온다. 그림자는 오른쪽 아래로 짧고 부드럽게.
- 시점: 정면 또는 위에서 약 30° 내려다본 3/4 시점. 극단적인 원근, 어안, 아주 낮은 시점은 쓰지 않는다.
- 분위기: 따뜻하고 차분하다. 극적인 조명, 어두운 밤 장면, 네온은 쓰지 않는다.

## 색

일러스트 색은 아래 목록 안에서만 고른다. 바탕 1색 + 대상 색 최대 6색.

### 바탕 (하나 고른다)

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| 크림 | `#F4EDE1` | 기본 |
| 연호박 | `#F7E4C7` | 발효·숙성 장면 |
| 연세이지 | `#E3E8DC` | 원료(곡물, 과일, 식물) 장면 |
| 연회청 | `#DEE3E6` | 증류, 냉각, 물 장면 |

- 흰 바탕(#FFFFFF)과 투명 바탕을 쓰지 않는다. 페이지 바탕이 흰색이라 그림 가장자리가 사라진다.
- 바탕은 단색이다. 바탕에 무늬나 풍경을 깔지 않는다.

### 대상 색

| 이름 | 값 | 쓰임 예 |
| --- | --- | --- |
| 호박 | `#E3AA58` | 술 액체, 곡물, 빛 |
| 짙은 호박 | `#B8711A` | 오크통, 나무, 숙성된 액체 |
| 고동 | `#5E360B` | 그림자 쪽 나무, 흙 |
| 구리 | `#B5653A` | 증류기, 금속 용기 |
| 세이지 | `#7F9470` | 잎, 식물, 누룩 곰팡이 |
| 짙은 청록 | `#2F5A5E` | 물, 유리, 차가운 금속, 대비가 필요한 부분 |
| 쌀 흰색 | `#FBF8F1` | 쌀, 거품, 김 |
| 먹 | `#2A2521` | 가장 어두운 부분. 순수한 검정은 쓰지 않는다 |

- 호박 계열은 사이트 브랜드 팔레트(`토큰.md` amber)와 같은 계열이다. 일러스트가 사이트 색을 이끈다.
- 형광색, 원색 빨강·파랑, 보라, 분홍을 쓰지 않는다.

## 구도

- 한 그림에 주인공 대상 하나. 과정이 여러 단계면 그림을 나눈다.
- 주 대상은 그림 가운데 영역에 두고, 가장자리 안전 영역 안쪽에는 중요한 부분을 두지 않는다. 안전 영역 값은 [`컴포넌트.md` 이미지 비율과 배치](컴포넌트.md#이미지-비율과-배치) 가 원본이다.
- 여백은 넉넉히. 대상이 그림 넓이의 30~60% 를 차지한다.
- 비율은 [`컴포넌트.md` 이미지 비율과 배치](컴포넌트.md#이미지-비율과-배치) 를 따른다.
- 과정 그림은 왼쪽에서 오른쪽으로 흐른다(재료 → 결과).
- 같은 대상(항아리, 오크통, 증류기)은 글이 달라도 같은 모양으로 그린다. 반복되는 대상은 첫 그림을 기준 이미지로 남겨 다음 생성의 참고로 쓴다.

## 대상 범위

그려도 되는 것:
- 원료: 곡물, 과일, 누룩, 효모를 단순화한 모양, 물.
- 도구와 설비: 항아리, 오크통, 발효조, 증류기, 병, 잔, 온도계 같은 일반적인 모양.
- 사람: 손과 팔, 또는 얼굴 표정이 없는 단순화된 인물. 작업하는 모습만.
- 미생물·분자처럼 눈에 안 보이는 것: 단순한 도형으로 추상화.

금지:
- 글자, 숫자, 기호, 글자처럼 보이는 낙서, 가짜 라벨, 눈금 숫자(사용자 결정).
- 특정 제품의 병 모양, 상표, 라벨, 로고, 특정 양조장 건물(사용자 결정).
- 실제 제품 사진이나 사진처럼 보이는 렌더링.
- 마시는 장면, 건배, 취한 모습, 술병을 든 인물(`아이덴티티.md` 원칙 6).
- 미성년자로 보이는 인물.
- 실존 인물을 닮은 얼굴.
- 다른 브랜드의 캐릭터나 그림체를 흉내 낸 스타일.

병과 잔은 라벨 없는 민무늬로 그린다. 병 모양은 원통형 몸통과 목만 있는 일반형이다.

## Recraft 운영 규칙

- **스타일 고정**: Recraft 커스텀 스타일 하나(style_id)로 모든 그림을 만든다. 커스텀 스타일은 이 문서 기준에 맞게 승인한 기준 이미지 5~10장으로 만든다(Recraft 는 최대 10장까지 받는다). 다른 브랜드의 그림을 기준 이미지로 넣지 않는다.
- **기록**: 쓰는 style_id, 모델 이름과 버전을 아래 "현재 설정" 에 적는다. 바꿀 때는 결정 기록에 남긴다. 모델을 바꾸면 기존 그림과 나란히 놓고 같은 그림체인지 판정한 뒤 바꾼다.
- **글자 방지**: 모델이 `no_text` 를 지원하면 켠다. `negative_prompt` 에 아래 금지 목록을 항상 넣는다.
- **색 지정**: `controls.colors` 에 이 문서의 대상 색 중 그 그림에 쓸 색을, `controls.background_color` 에 바탕 색 하나를 넣는다.
- **출력**: 래스터 이미지로 받는다. 벡터(SVG) 출력은 쓰지 않는다.
- **크기**: 원본 최소 가로([`컴포넌트.md` 이미지 비율과 배치](컴포넌트.md#이미지-비율과-배치))를 넘게 모델 크기를 고르거나 Recraft 업스케일을 쓴다. 모델이 정확한 16:9 를 주지 않으면 가장 가까운 가로형으로 받고 16:9 로 가운데를 잘라낸다.
- **보관**: 원본은 글 폴더(`apps/web/src/content/posts/{id}/`)에 PNG 로 둔다. 화면용 변환은 빌드가 한다.

### 프롬프트 틀

프롬프트는 영어로 쓴다. 뒤쪽 스타일 문장은 모든 그림에서 똑같이 쓴다.

```
{장면: 무엇이 무엇을 하는지 한 문장}. {주 대상과 위치}. {보조 대상}.
Clean advertising illustration, simplified flat shapes with soft gradients,
no outlines, soft light from top left, gentle short shadows,
three-quarter view from slightly above, generous empty space,
subject centered, solid {바탕 이름} background.
```

### negative_prompt 기본값

```
text, letters, words, numbers, typography, captions, labels, logos, brand names,
watermark, signature, scribbles resembling writing, product packaging,
photorealistic, photo, noise, grain, paper texture, outlines, dark night scene,
neon, people drinking, toasting, drunk, children
```

## 판정 체크리스트

하나라도 걸리면 반려한다.

- [ ] 글자, 숫자, 글자처럼 보이는 무늬가 없다(확대해서 병, 통, 벽을 확인한다).
- [ ] 상표, 라벨, 로고, 특정 제품으로 알아볼 수 있는 모양이 없다.
- [ ] 마시는 장면, 취한 모습, 미성년자로 보이는 인물이 없다.
- [ ] 바탕이 네 가지 바탕 색 중 하나이고 단색이다.
- [ ] 이 문서 색 목록 밖의 눈에 띄는 색이 없다.
- [ ] 외곽선과 질감이 없다.
- [ ] 빛이 왼쪽 위에서 온다.
- [ ] 주 대상이 가장자리 안전 영역 안에 있다.
- [ ] 같은 사이트의 기존 그림 옆에 놓았을 때 같은 사람이 그린 것처럼 보인다.
- [ ] 화면용 파일 무게가 `컴포넌트.md` 기준 이하다.
