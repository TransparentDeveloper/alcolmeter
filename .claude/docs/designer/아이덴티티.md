# 아이덴티티

## 한 줄 정의

alcolmeter 는 술이 어떻게 만들어지는지를 검수된 사실과 그림으로 차근차근 보여주는 읽을거리다.

## 규모 전제

사이트 소개와 발행 계획은 루트 `README.md` 를 따른다. 3년이면 450편 이상이 쌓이므로 규칙은 글이 수백 편 쌓여도 같은 모습이 유지되는 쪽으로 정한다.

## 누구를 위한가

1. **주 독자: 루트 `README.md` 의 핵심 타깃.** 양조 지식이 없어도 한 편을 끝까지 따라올 수 있어야 한다.
2. **인용하는 사람: 기자, 작가, 교육자, 다른 블로거, 검색 엔진과 AI 답변.** 문장 하나, 수치 하나를 떼어 가도 뜻과 출처가 유지되어야 한다.

두 대상이 부딪히면 1번을 따른다. 사람이 읽기 좋은 글이 결국 인용된다.

## 페이지를 무엇을 위해 구성하는가

페이지는 목록과 상세 두 종류다(사용자 결정).

| 페이지 | 독자가 해야 하는 일 | 그래서 페이지가 하는 일 |
| --- | --- | --- |
| 목록 | 다음에 읽을 글을 고른다 | 그림과 제목, 요약으로 글의 주제를 한눈에 구분하게 한다 |
| 상세 | 한 공정을 끝까지 이해하고, 필요한 사실을 가져간다 | 방해 없는 본문, 공정마다 그림, 작성일, 수정일, 출처를 보이게 둔다 |

## 성격

- **말투**: 정확하고, 차분하고, 친절하다. 설명하는 사람이지 파는 사람이 아니다.
- **시각**: 따뜻한 종이 같은 바탕, 호박색 한 가지 강조, 선명하고 단순한 광고 일러스트. 화면 장식은 최소로 하고 그림이 분위기를 만든다.

## 디자인 원칙

원칙끼리 부딪히면 번호가 앞선 원칙이 이긴다.

### 1. 읽기가 먼저다

본문 가독성, 이미지 로딩 속도, 접근성(WCAG 2.2 AA)이 장식보다 우선한다.

하지 않는 것:
- 본문을 가리거나 끊는 요소(팝업, 배너, 화면에 고정되는 헤더, 자동 재생)를 두지 않는다.
- 본문 칼럼을 `$size.content`(`토큰.md` 레이아웃)보다 넓게 만들지 않는다.
- 본문 글자에 음수 자간을 주지 않는다.
- 이미지 위에 글자를 얹지 않는다.

### 2. 근거가 보인다

공신력은 디자인으로 드러난다. 작성일, 수정일, 출처를 숨기지 않는다.

하지 않는 것:
- 출처 없는 수치를 강조 스타일(굵게, 색)로 돋보이게 하지 않는다.
- 과장하거나 낚는 제목을 쓰지 않는다.
- 수정일이 있는데 작성일만 보여주지 않는다.

### 3. 그림으로 이해시킨다

공정 하나에 그림 하나 이상을 둔다. 그림은 설명을 돕는 정보이지 빈자리를 채우는 장식이 아니다.

하지 않는 것:
- 이미지 안에 글자를 넣지 않는다(사용자 결정).
- 특정 제품의 사진, 상표, 라벨을 쓰지 않는다(사용자 결정).
- 주제와 관계없는 분위기용 이미지를 넣지 않는다.

### 4. 한 사람이 만든 것처럼 보인다

모든 화면과 그림은 같은 토큰, 같은 컴포넌트, 같은 일러스트 스타일에서 나온다.

하지 않는 것:
- 글마다 다른 색, 다른 레이아웃, 다른 그림체를 쓰지 않는다.
- 토큰을 거치지 않은 값을 CSS 에 직접 쓰지 않는다.
- 일러스트 스타일(Recraft style_id, 모델)을 기록 없이 바꾸지 않는다.

### 5. 적게 만든다

페이지 두 종류, 필요한 컴포넌트만 만든다. 새 색, 새 크기, 새 변형은 기존 것으로 안 되는 이유가 있을 때만 더한다.

하지 않는 것:
- 독자 상호작용 UI(좋아요, 댓글, 구독 팝업)를 만들지 않는다. 독자는 읽기만 한다(사용자 결정).
- "조금 더 눈에 띄게" 수준의 이유로 토큰이나 변형을 늘리지 않는다.

### 6. 술을 권하지 않는다

술을 만드는 법을 설명하지, 마시라고 하지 않는다.

하지 않는 것:
- 마시는 장면, 취한 모습, 건배 장면을 그리지 않는다.
- 음주를 부추기는 문구와 버튼을 두지 않는다.
- 건강 효능을 근거 없이 말하지 않는다.
