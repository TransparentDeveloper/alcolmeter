# 디자인 토큰

글꼴, 글자 크기, 굵기, 행간은 `글꼴.md` 에 있다. 이 문서는 층위, 이름 규칙, 색, 간격, 레이아웃, 모서리, 그림자, 모션을 다룬다.

## 층위

SEED 의 구조를 따른다. 값에 이름을 주는 층과 의도에 이름을 주는 층을 나눈다.

| 층 | 이름 예 | 내용 | 누가 참조하나 |
| --- | --- | --- | --- |
| 1층 팔레트 | `$color.palette.amber-700` | 색의 실제 값 | 2층 역할 토큰, 일러스트 기준 문서만 |
| 1층 스케일 | `$dimension.x4`, `$radius.r3`, `$duration.d1` | 크기·시간의 유한한 단계 | 2층 역할 토큰, 컴포넌트 명세 |
| 2층 역할 | `$color.fg.neutral`, `$dimension.gutter`, `$text-style.article-body` | 디자인 의도 | 컴포넌트 명세, 화면 CSS |
| 3층 컴포넌트 명세 | `PostCard.title.color = $color.fg.neutral` | 컴포넌트 부위별 토큰 연결 | 구현 코드 |

규칙:
- 화면과 컴포넌트 CSS 의 색은 반드시 2층 역할 토큰을 쓴다. 팔레트 직접 참조는 반려한다.
- 간격, 모서리, 시간은 역할 토큰이 있으면 역할 토큰, 없으면 스케일 토큰을 쓴다. 스케일에 없는 값은 쓰지 않는다.
- 같은 값이라도 의미가 다르면 다른 역할 토큰으로 둔다. 값이 아니라 의미 단위로 바꿀 수 있어야 한다(SEED 역할 색 원칙).
- 토큰 추가·삭제·값 변경은 `결정-기록.md` 에 먼저 남긴다.

## 이름 규칙

- 형식: `${분류}.{속성}.{역할}-{변형}-{상태}`. 뒤쪽 조각은 필요할 때만 붙인다.
  - 색: `$color.{fg|bg|stroke}.{역할}[-{변형}][-{상태}]` 예: `$color.fg.neutral-muted`, `$color.bg.critical-weak`
  - 팔레트: `$color.palette.{색 이름}-{단계}` 예: `$color.palette.gray-900`
  - 스케일: `$dimension.x{배수}`(4px 배수), `$radius.r{배수}`, `$duration.d{단계}`, `$font-size.t{단계}`
  - 소수 배수는 밑줄: `$dimension.x0_5`
- 역할 이름은 SEED 어휘를 쓴다: `neutral`, `brand`, `critical`. 변형은 `muted`, `subtle`, `weak`. 새 어휘는 결정 기록 후에만 쓴다.
- 영어 소문자와 하이픈만 쓴다.
- CSS 변수로 내보낼 때는 `$` 를 떼고 점을 하이픈으로 바꾸고 접두사 `--am-` 를 붙인다.
  - `$color.fg.neutral-muted` → `--am-color-fg-neutral-muted`
  - `$dimension.x0_5` → `--am-dimension-x0_5`

## 테마

- 라이트 테마 하나로 시작한다. **사용자 결정(추천안 승인, 2026-09-30)**
- 역할 토큰은 테마별 값을 가질 수 있는 구조로 만든다. 다크 모드를 더할 때 역할 토큰 값만 추가하고 컴포넌트는 고치지 않는다.
- 움직임은 SEED 처럼 `preferred` 와 `reduced` 두 모드를 둔다(아래 모션).

## 색

### 1층 팔레트

따뜻한 회색(gray), 호박색(amber), 빨강(red) 세 계열만 둔다. 회색은 노란 기가 약간 도는 종이 톤이다.

| 토큰 | 값 | 토큰 | 값 | 토큰 | 값 |
| --- | --- | --- | --- | --- | --- |
| `gray-00` | `#FFFFFF` | `amber-50` | `#FCF4E8` | `red-50` | `#FDEFED` |
| `gray-50` | `#FAF8F5` | `amber-100` | `#F7E4C7` | `red-100` | `#F9D5D0` |
| `gray-100` | `#F3F0EB` | `amber-200` | `#EFCB94` | `red-600` | `#B42A1F` |
| `gray-200` | `#E7E2DB` | `amber-300` | `#E3AA58` | `red-700` | `#8E2018` |
| `gray-300` | `#D5CEC5` | `amber-400` | `#D18B2C` | | |
| `gray-400` | `#B3ABA1` | `amber-500` | `#B8711A` | | |
| `gray-500` | `#8C847A` | `amber-600` | `#9A5A10` | | |
| `gray-600` | `#6B645C` | `amber-700` | `#7C470D` | | |
| `gray-700` | `#534D47` | `amber-800` | `#5E360B` | | |
| `gray-800` | `#3B3632` | | | | |
| `gray-900` | `#231F1C` | | | | |

팔레트 전체가 UI 에 쓰이지는 않는다. amber 의 중간 단계는 일러스트 색 기준(`일러스트.md`)의 기준점이다.

### 2층 역할 색

| 토큰 | 팔레트 | 쓰임 |
| --- | --- | --- |
| `$color.fg.neutral` | gray-900 | 본문, 제목 |
| `$color.fg.neutral-muted` | gray-700 | 요약, 캡션, 표 머리 |
| `$color.fg.neutral-subtle` | gray-600 | 날짜 등 메타 정보, 푸터 |
| `$color.fg.brand` | amber-700 | 본문 링크 |
| `$color.fg.critical` | red-700 | 주의 콜아웃의 제목 |
| `$color.bg.layer-default` | gray-00 | 페이지 바탕 |
| `$color.bg.neutral-weak` | gray-50 | 참고 콜아웃, 표 머리, 이미지 로딩 전 자리 |
| `$color.bg.critical-weak` | red-50 | 주의 콜아웃 |
| `$color.stroke.neutral-subtle` | gray-200 | 구분선, 표 선 |
| `$color.stroke.focus-ring` | amber-700 | 키보드 focus 표시 |

규칙:
- 브랜드 색(amber)은 링크와 focus 표시에만 쓴다. 제목, 배경, 버튼을 호박색으로 칠하지 않는다. 호박색은 일러스트가 충분히 보여준다.
- 빨강은 안전·법률 관련 주의에만 쓴다. 단순 강조에 쓰지 않는다.
- 색만으로 정보를 전달하지 않는다. 링크는 밑줄, 주의 콜아웃은 "주의" 라벨을 함께 둔다(WCAG 1.4.1).

### 대비 계산 (WCAG 2.x 상대 휘도 공식으로 계산)

본문 글자는 4.5:1, 큰 글자와 UI 요소 경계·focus 표시는 3:1 이 AA 기준이다(WCAG 2.2 1.4.3, 1.4.11).

| 전경 | 배경 | 대비 | 판정 |
| --- | --- | --- | --- |
| fg.neutral (gray-900) | bg.layer-default (gray-00) | 16.35:1 | 통과 |
| fg.neutral (gray-900) | bg.neutral-weak (gray-50) | 15.43:1 | 통과 |
| fg.neutral (gray-900) | bg.critical-weak (red-50) | 14.60:1 | 통과 |
| fg.neutral-muted (gray-700) | bg.layer-default | 8.33:1 | 통과 |
| fg.neutral-muted (gray-700) | bg.neutral-weak | 7.86:1 | 통과 |
| fg.neutral-subtle (gray-600) | bg.layer-default | 5.83:1 | 통과 |
| fg.neutral-subtle (gray-600) | bg.neutral-weak | 5.50:1 | 통과 |
| fg.brand (amber-700) | bg.layer-default | 7.60:1 | 통과 |
| fg.critical (red-700) | bg.critical-weak | 7.91:1 | 통과 |
| stroke.focus-ring (amber-700) | bg.layer-default | 7.60:1 | 통과(3:1 기준) |
| stroke.focus-ring (amber-700) | bg.neutral-weak | 7.17:1 | 통과(3:1 기준) |
| stroke.focus-ring (amber-700) | bg.critical-weak | 6.78:1 | 통과(3:1 기준) |

참고: gray-500(3.69:1)과 amber-500(3.88:1)은 흰 바탕에서 4.5:1 에 못 미친다. 글자색 역할에 연결하지 않는다.

| 토큰 | 값 | 토큰 | 값 |
| --- | --- | --- | --- |
| `$dimension.x1` | 4px | `$dimension.x8` | 32px |
| `$dimension.x2` | 8px | `$dimension.x10` | 40px |
| `$dimension.x3` | 12px | `$dimension.x12` | 48px |
| `$dimension.x4` | 16px | `$dimension.x14` | 56px |
| `$dimension.x5` | 20px | `$dimension.x16` | 64px |
| `$dimension.x6` | 24px | `$dimension.x24` | 96px |

### 2층 역할 간격

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `$dimension.gutter` | base x4(16px), md 이상 x6(24px) | 화면 가장자리와 콘텐츠 사이. SEED `global-gutter`(16px)와 SEED 레이아웃 md 이상 여백(24px) |
| `$dimension.paragraph-gap` | x6(24px) | 본문 문단, 목록, 표 사이 |
| `$dimension.heading-2-gap` | 위 x14(56px), 아래 x4(16px) | 본문 h2 앞뒤 |
| `$dimension.heading-3-gap` | 위 x10(40px), 아래 x3(12px) | 본문 h3 앞뒤 |
| `$dimension.figure-gap` | x10(40px) | 본문 그림 앞뒤 |
| `$dimension.caption-gap` | x3(12px) | 그림과 캡션 사이 |
| `$dimension.card-gap-x` | x8(32px) | 목록 카드 가로 간격 |
| `$dimension.card-gap-y` | x12(48px) | 목록 카드 세로 간격 |
| `$dimension.section-gap` | x24(96px) | 본문 끝과 푸터 등 페이지 큰 구획 사이 |

## 레이아웃

### 폭 (rem 으로 둔다. 사용자가 글자 크기를 키우면 한 줄 글자 수가 유지된다)

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `$size.content` | 40rem (640px) | 본문 칼럼. 17px 본문에서 한 줄 공백 포함 약 55자, 한글 음절 약 45자(Paperlogy 글자 폭: 한글 0.88em, 공백 0.22em) |
| `$size.wide` | 60rem (960px) | 상세 커버, 넓은 그림 |
| `$size.page` | 65rem (1040px) | 목록 격자, 헤더, 푸터 |

### 중단점 (모바일 우선)

| 이름 | 시작 폭 | 바뀌는 것 |
| --- | --- | --- |
| base | 0 | 목록 1열, 여백 16px |
| md | 768px | 목록 2열, 여백 24px |
| lg | 1024px | 목록 3열 |

## 모서리

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `$radius.r3` | 12px | 모든 이미지, 콜아웃, 카드의 focus 표시 |
| `$radius.full` | 9999px | 알약 모양이 필요할 때만(현재 쓰는 곳 없음) |

모서리 값은 이 두 개뿐이다. 표와 인용문에는 모서리를 주지 않는다.

## 그림자

그림자 토큰은 두지 않는다. 떠 있는 UI(고정 헤더, 시트, 대화상자)가 없어서 쓸 곳이 없다. 영역 구분은 바탕색(`bg.neutral-weak`)이나 선(`stroke.neutral-subtle`)으로 한다. 떠 있는 UI 가 생기면 그때 결정 기록과 함께 추가한다.

## 모션

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `$duration.d1` | 100ms | 스케일 |
| `$duration.d2` | 200ms | 스케일 |
| `$duration.color-transition` | d1 | 링크·카드 제목의 색과 밑줄 변화 |
| `$timing-function.easing` | `ease-out` | 모든 전환 |

규칙:
- 움직임은 색과 밑줄 변화에만 쓴다. 이미지 확대, 카드 들림, 스크롤 등장 효과, 페이지 전환 애니메이션은 쓰지 않는다.
- `prefers-reduced-motion: reduce` 에서는 모든 duration 을 0 으로 바꾼다(motion `reduced` 모드).
- 200ms 를 넘는 움직임은 만들지 않는다.
