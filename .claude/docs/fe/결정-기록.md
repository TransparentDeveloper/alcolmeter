# 프런트엔드 결정 기록

규칙을 만들거나 바꿀 때마다 한 항목을 추가한다. 항목은 지우지 않는다. 뒤집으면 새 항목을 쓰고 이전 번호를 적는다.

형식: 번호, 날짜, 결정, 구분(사용자 결정 / fe 결정 / 임시), 이유, 버린 안.

## F-001 ds 를 `packages/ds` 로 분리

- 날짜: 2026-10-05
- 구분: 사용자 결정(디자인 결정 기록 D-001 "ds 는 모노레포 `packages/` 아래 패키지로 구현")을 따른 fe 구현
- 결정: `@alcolmeter/ds` 패키지에 토큰, 글꼴, 기본 스타일, 명세된 컴포넌트를 둔다. 빌드 단계 없이 소스를 내보내고 앱은 `workspace:*` 로 쓴다. `astro` 는 peerDependency.
- 이유: D-001 이 사용자 결정이다. 앱이 하나뿐이라 재사용 이점은 아직 없지만, 패키지 경계가 "ds 는 콘텐츠와 라우팅을 모른다"를 import 수준에서 강제하고, 글꼴 라이선스 파일의 위치(`designer/글꼴.md`: ds 패키지의 글꼴 폴더)도 패키지를 전제한다. 빌드 단계가 없어서 분리 비용은 package.json 하나다.
- 버린 안: `apps/web/src/ds` 폴더로 두기(D-001 과 충돌, 경계가 관례로만 남는다). ds 를 빌드해 dist 로 내보내기(소비자가 Astro 앱 하나라 이득이 없다).

## F-002 토큰은 CSS 변수, 텍스트 스타일은 font 단축 값

- 날짜: 2026-10-05
- 구분: fe 결정
- 결정: 모든 토큰을 `tokens.css` 의 `:root` CSS 변수로 둔다. 텍스트 스타일은 `font` 단축 속성 값 하나로 둔다. 위·아래 값이 다른 간격 토큰은 `-top`/`-bottom` 으로 나눈다.
- 이유: 정적 사이트라 런타임 테마 전환이 없어도 변수면 다크 모드 때 역할 토큰 값만 바꿀 수 있다(D-005). `font` 단축 값이면 크기·굵기·행간·글꼴을 따로 조합하지 못하게 막는다(`designer/글꼴.md` 위계 규칙).
- 버린 안: TS 객체에서 CSS 생성(생성 도구가 필요하다). 텍스트 스타일 유틸리티 클래스(scoped 스타일과 섞어 쓰게 된다).

## F-003 컴포넌트 폭은 공용 클래스 세 개

- 날짜: 2026-10-05
- 구분: fe 결정
- 결정: `.am-width-content`, `.am-width-wide`, `.am-width-page` 를 `base.css` 에 두고 컴포넌트가 붙인다. 넓은 그림(Figure wide)만 본문 칼럼 안에서 음수 여백으로 넓힌다.
- 이유: 같은 폭 계산이 6개 컴포넌트에 반복된다.
- 버린 안: 본문을 그리드 칼럼으로 짜서 넓은 그림을 열로 펼치기(그리드에서는 여백이 겹치지 않아 제목 앞뒤 간격 규칙을 다시 짜야 한다).

## F-004 Paperlogy 는 공식 woff2 전체 파일로 임시 배포 (규칙과 차이)

- 날짜: 2026-10-05
- 구분: 임시
- 결정: 공식 저장소 `woff2/` 의 300·500·700 전체 파일(각 약 430KB)을 그대로 쓴다. `designer/글꼴.md` 의 분할 서브셋(unicode-range)과 첫 조각 preload 는 아직 적용하지 않았다. preload 는 전체 파일이 커버 이미지와 대역폭을 다투므로 걸지 않았다. 대체 글꼴 `@font-face` 와 `font-display: swap` 은 규칙대로 적용했다.
- 이유: 서브셋을 만들려면 fontTools 같은 글꼴 도구가 필요한데, 사용자 요청 없이 도구를 설치하지 않는다.
- 해소 조건: 글꼴 도구 사용 승인 후 서브셋 생성 스크립트를 ds 에 두고 `fonts.css` 를 조각별 선언으로 바꾼다. 그때 이 항목을 닫는 새 항목을 쓴다.
- 버린 안: 시스템 글꼴 유지(`designer/README.md` 차이 목록이 남는다).

## F-005 참고 자료(SourceList)는 GFM 각주로 구현

- 날짜: 2026-10-05
- 구분: fe 결정
- 결정: 글은 `[^1]` 각주를 쓰고, 마크다운 처리기(Astro 7 기본 satteri)가 본문 끝에 만드는 각주 section 을 `Prose` 가 SourceList 명세대로 꾸민다. 목차는 각주 제목(slug `footnote-label`)을 뺀다.
- 이유: 각주 번호와 목록 번호 일치, 서로 링크하기(`designer/컴포넌트.md` SourceList)를 처리기가 보장한다. frontmatter 로 따로 받으면 번호 맞춤을 사람이 해야 한다.
- 남은 문제: 각주 제목이 기본값 "Footnotes", 돌아가기 링크 이름이 "Back to reference N" 이다. 바꾸려면 `astro.config.mjs` 에서 `@astrojs/markdown-satteri` 의 `satteri({ features: { gfm: { footnotes: { label, backLabel } } } })` 를 써야 하고, 이 패키지를 앱의 직접 의존성으로 올려야 한다(이미 astro 가 같은 0.4.2 를 설치함). 사용자 승인 전이라 하지 않았다. 돌아가기 기호 `↩` 은 Paperlogy 에 글리프가 없어 대체 글꼴로 그려진다.
- 버린 안: frontmatter `sources` 배열(위 이유). MDX 컴포넌트로 h2 바꿔치기(md 글에는 안 되고 정적 최적화에 막힐 수 있다).

## F-006 명세에 없어 임시로 넣은 값

- 날짜: 2026-10-05
- 구분: 임시(designer 확인 필요)
- 결정: 아래는 `designer/컴포넌트.md` 에 값이 없어 기존 토큰 중 가까운 것을 넣었다. designer 가 값을 정하면 바꾼다.
  - 목록: feature 카드와 격자 사이 `card-gap-y`.
  - 상세: Cover 와 다음 요소 사이, 목차와 본문 사이 `figure-gap`. 사이트 헤더와 ArticleHeader 사이 0.
  - 목차: 위아래 선 안쪽 여백 `x4`, 라벨 "목차" 글자 스타일은 본문 상속(`article-body`), 번호 목록 들여쓰기 `x6`, 링크 위아래 `x2`(누를 영역 46px).
  - 본문: 목록 들여쓰기 `x6`, 표 칸 여백 `x2`·`x3`, 표 머리 글자 굵기 medium·왼쪽 정렬, Callout 라벨과 내용 사이 `x2`, 각주 항목 사이 `x2`, 각주 번호 글자 `t1`·medium.
  - 카드 제목 hover 밑줄의 두께와 띄움은 브라우저 기본값.
- 이유: 화면을 그리려면 값이 필요하다. 새 값을 만들지 않고 기존 스케일·역할 토큰만 썼다.

## F-007 SiteHeader 로고의 누를 영역

- 날짜: 2026-10-05
- 구분: fe 결정
- 결정: 로고에 위아래 안쪽 여백 `x2`, 헤더 위아래 여백 `x4` 를 준다. 글자 바깥 간격은 명세대로 `x6` 이 되고 로고 누를 영역은 44px 이 된다.
- 이유: `designer/컴포넌트.md` 공통 상태 규칙의 "헤더 로고 세로 44px 이상 권장"과 SiteHeader "위아래 간격 x6" 을 스케일 값만으로 함께 맞춘다.
- 버린 안: `min-height: 44px`(스케일에 없는 값).

## F-008 표 가로 스크롤은 CSS 만으로

- 날짜: 2026-10-05
- 구분: fe 결정
- 결정: 본문 `table` 에 `display: block; overflow-x: auto` 를 준다. 감싸는 요소를 만들지 않는다.
- 이유: 감싸려면 마크다운 처리기 플러그인이나 MDX 컴포넌트 바꿔치기가 필요하다. 최신 Chrome·Firefox 는 display 를 바꿔도 표 의미를 유지하고, Chrome 은 스크롤 영역에 키보드 focus 를 준다.
- 위험: 일부 Safari·스크린 리더 조합에서 표 의미가 약해질 수 있다. 넓은 표가 실제로 생기면 확인한다.
- 버린 안: `div` 로 감싸고 `tabindex="0"`(처리기 설정이 필요하다, F-005 와 같은 의존성 문제).

## F-009 designer D-031·D-032 반영 (F-006 닫음, F-005 일부 해소)

- 날짜: 2026-10-05
- 구분: fe 결정(designer D-031, D-032 구현)
- 결정:
  - F-006 임시값은 D-031 로 확정되거나 바뀌어 닫는다. 바뀐 것만 적는다. 헤더와 main 사이 `x6`, Cover·목차 아래 `x10`, 목차 안쪽 여백 위 `x4`·아래 `x2`, 목차 라벨 `meta` + `fg.neutral-subtle`, 카드 제목·목차 hover 밑줄 2px·띄움 3px, 각주 번호 `article-note` + 위첨자 행간 0.
  - 헤더와 main 사이 간격은 페이지 뼈대 간격이라 SiteHeader 가 아니라 앱 `Base.astro` 의 `main` 위 안쪽 여백으로 둔다. 컴포넌트는 자기 바깥 간격 중 명세에 "아래 간격"으로 적힌 것만 가진다.
  - 각주 돌아가기 링크에 좌우 `x2` 와 `inline-block` 을 준다. 인라인 상자는 글자 높이만 누를 영역이 되므로 행간 t1(24px)을 높이로 쓰려면 inline-block 이 필요하다.
  - 처리기가 각주 제목에 붙이는 `sr-only` 를 `base.css` 에서 `.visually-hidden` 과 같은 규칙으로 정의한다. 영어 "Footnotes" 제목이 화면에서 사라진다.
- 남은 차이(F-005, 의존성 승인 대기): 보이는 "참고 자료" h2, 돌아가기 내용 `↑`, 이름 "각주 {N} 위치로 돌아가기". 지금은 숨긴 "Footnotes" 제목, `↩`, "Back to reference N" 이다.
- 버린 안: 각주 제목 글자를 CSS `content` 로 "참고 자료"처럼 바꿔 보이기(보이는 글자와 스크린 리더가 읽는 이름이 달라진다).

## F-010 리뷰 반영, 표 스크롤 상자 (F-008 대체)

- 날짜: 2026-10-06
- 구분: fe 결정(커밋 전 리뷰, designer D-036·D-038 구현)
- 결정:
  - 본문 표는 ds `ProseTable`(`tabindex="0"`, `role="region"`, `aria-label="표"` 상자 + `table`)로 그린다. 상세 페이지가 MDX `components` 의 `table` 로 넘긴다. F-008 의 `display: block` 은 없앤다.
  - 그래서 글은 `index.mdx` 만 받는다(`content.config.ts` glob). `.md` 글은 요소 바꿔치기가 안 돼 D-038 을 지킬 수 없다. 기존 글과 에이전트 문서도 모두 `index.mdx` 기준이다.
  - Prose 간격 선언 순서를 문단 → 그림 → 제목 아래 → 제목 위로 바꿔 D-036 을 맞춘다.
  - OG 이미지는 커버를 1200×630 가운데 자르기로 만든다(`designer/컴포넌트.md` 이미지 비율과 배치).
  - 표 칸은 `overflow-wrap: break-word`. 전역 `anywhere` 는 최소 폭 계산에 들어가 칸이 글자 단위로 찌그러진다.
  - ArticleHeader 수정일 앞 ` · 수정 ` 은 문자열 식으로 고정한다. JSX 줄바꿈 공백은 빌드에서 사라진다.
  - ds `tsconfig.json` 에 `astro/client` 타입을 넣는다(`ImageMetadata`, `astro:assets`).
- 이유: D-038 의 rehype 방식은 Astro 7 에서 `@astrojs/markdown-satteri`(hastPlugins) 나 `@astrojs/markdown-remark`(legacy rehypePlugins) 를 import 해야 해서 의존성이 생긴다. MDX 컴포넌트 바꿔치기는 의존성 없이 빌드 시점에 끝나고 클라이언트 JS 도 없다. MDX 정적 최적화(`optimize`)는 기본값 false 라 바꿔치기가 막히지 않는다. 켜면 다시 확인한다.
- 확인: D-037(feature 카드만 즉시·우선 로딩, 격자는 지연)은 현재 코드와 같다.
- 버린 안: 설정 파일 안 rehype 함수(위 의존성). `.md` 를 남기고 표 규칙 예외로 두기(규칙이 글 형식에 따라 갈린다).
