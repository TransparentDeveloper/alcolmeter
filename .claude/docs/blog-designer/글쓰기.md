# 글쓰기

서비스 화면 문구(버튼, 안내 문구, 빈 상태, 날짜 같은 메타 표시, 메타 태그의 고정 문구)의 말투를 정한다. 블로그 글의 말투와 형식은 `.claude/docs/blog-content-reviewer/글쓰기.md` 가 맡는다.

## 어조

- 문체는 해요체만 쓴다. 블로그 글은 해요체와 하십시오체를 섞지만, 화면 문구는 짧아 한 화면 안에서 문체가 섞이면 어긋나 보인다.
  - 좋음: "아직 글이 없어요"
  - 나쁨: "아직 글이 없습니다"
- 문체 말고 어조와 금지 표현(과장, 유행어, 이모지, 음주 권유)은 블로그 글쓰기 문서의 "어조" 절을 따른다. **사용자 결정**
- 화면 문구에는 느낌표를 쓰지 않는다.

## 숫자와 날짜

- 화면에 보이는 숫자, 단위, 날짜 표기는 블로그 글 규칙의 "숫자와 단위" 절을 따른다.
