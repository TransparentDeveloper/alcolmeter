# alcolmeter

술이 무엇이고 어떻게 다른지, 고르는 데 필요한 것을 풀어 주는 블로그다. 제조 과정과 레시피를 단계별로 설명하지 않는다. 레시피는 별도 서비스가 맡는다.

글은 한 사람이 쓰고, 전문 양조가가 최종본을 검수한다. 독자는 읽기만 한다. 광고와 협찬은 없다.

검색에 잘 노출되고 공신력 있는 정보로 인용되는 것이 목표다. 그래서 검색 봇보다 사람이 읽기 좋은 페이지를 우선한다.

최소 3년 동안 주 3편 이상 발행한다.

핵심 타깃은 술을 마시기 시작한 지 얼마 안 된 젊은 청년이다.

주소: https://alcolmeter.kr

## 구성

- `apps/blog`: 블로그 사이트

## 실행

Node 22.12 이상과 pnpm 이 필요하다.

```
pnpm install
pnpm dev       개발 서버
pnpm build     전체 빌드
```
