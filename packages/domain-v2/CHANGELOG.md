## [0.1.0] — 2026-06-20

> *하지를 하루 앞둔 유월, 발효가 가장 거세지는 철에 새 계산 노트의 첫 장을 폅니다. 아직 눈금은 임시이나, 재료를 올리면 도수가 어렴풋이 비치기 시작하였습니다.*

- **새 도메인 라이브러리** — 재료 총량과 발효횟수를 넣으면 예상 도수·생산량·담금별 투입 분배를 돌려주는 발효주 추정 엔진입니다 (`LiquorController.ferment()`).
- **단계별 발효 시뮬레이션** — 나눠 담글수록 도수가 오르는 동역학을 모델링했습니다 (잠재 도수 + 효모 내성 상한, 농도 초과분은 잔당으로).
- **계층 구조** — `interface → application → calculator → model`로 책임을 나누고, 도메인 모델은 외부에 노출하지 않습니다.
- **재료 모델** — 쌀·물·누룩을 `Ingredient` 추상 위에 올려, 추후 배·포도 등으로 확장할 수 있게 두었습니다.
- ⚠️ **아직 초기 버전** — 계수는 캘리브레이션 전 임시값이며, 기존 `domain`을 대체하기 전의 골격 단계입니다.
